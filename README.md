# PageTurner Online Bookstore

A modern, responsive frontend for an online bookstore built with HTML, CSS, Bootstrap, JavaScript, Font Awesome, and Google Fonts.

## Structure
- index.html - Home page
- shop.html - Product listing and filtering
- book-details.html - Detailed book view
- cart.html - Shopping cart
- checkout.html - Checkout form
- wishlist.html - Saved books
- login.html - Sign in page
- register.html - Sign up page
- profile.html - User profile
- about.html - Company story
- contact.html - Contact page
- 404.html - Error page

## Run locally
Open index.html in a browser, or serve the folder with a simple static server.
